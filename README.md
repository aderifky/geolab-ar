
# GeoLab AR - Praktikum Tanah (3D Interaktif)
Simple WebAR demo using A-Frame + AR.js with interactive 3D primitives (no external .glb required).
Open `index.html` via HTTPS hosting (GitHub Pages or Netlify). Use 'hiro' marker to test.
Marker 'hiro' image: https://raw.githubusercontent.com/AR-js-org/AR.js/master/aframe/examples/marker-training/examples/pattern-files/pattern-hiro.png
Replace openLKS() url in script.js with your Google Form link.
